# Virtual Sande — local document preview and dual WPA rings v1
Date: 2026-11-24. Status: development candidate, not merged or deployed.

Scope: incremental public interface enhancement based on the Phase 1 release (#753), without enabling the private document/model API in #752. Up to 20 selected files in one in-memory conversation session; maximum 15 MiB each. File picker and drag/drop; filename, type, size, individual removal and clear. No file bytes, names or previews are attached to the /ask payload. The user may independently type or paste text into the existing public chat. The interface explicitly distinguishes local preview from AI document reading. No server storage, OCR, or document analysis. Refresh or clear resets the selected files.

Formats: PDF opens via a local blob link in the browser's native viewer (not page-rendering in the chat); PNG/JPG/JPEG displayed locally; UTF-8 JSON/CSV/MD/Markdown/TXT as bounded literal text (not executed HTML); JSON formatting only for complete valid JSON. DOCX reads bounded word/document.xml from the ZIP archive and shows paragraph text; styles, images, headers and other layout elements are not reproduced. Legacy binary DOC and nonstandard DOX are not supported. Signature checks are format guards, not malware certification. For DOCX, decompression is limited to 2 MiB of XML with archive boundary validation and rejection of DTD/entity declarations. Text previews capped at 120,000 bytes/characters as applicable, with a limitation notice. Browser support is required for deflate-raw and native PDF rendering. The user controls opening PDF; no network upload by preview module. Blob URLs are revoked when switching/closing/removing previews or clearing.

Waiting indicator: original WPA logo at the centre, two symmetric concentric rings rotating in opposite directions. Reduced-motion preference disables animation. Existing request deadline, cancellation, elapsed response time, voice, edit and planner remain intact. Cache-version suffix refreshed without changing the canonical public endpoint.

Acceptance: unit tests verify 20/21, size/format checks, literal text, binary signatures, stored/deflated DOCX, decompression limits and invalid input; Chrome desktop/mobile tests check picker/drop, mixed file previews, local-only behavior, ring count/direction/centering and existing public chat regressions. CI tests must pass on exact head. PDF link is tested, not native PDF viewer rendering. No real sensitive files or external provider calls in tests. Actual production CSP, browser support and live visual acceptance remain to be verified before release. Separate owner approval required to merge this enhancement. #752 remains a protected pilot candidate with its separate release gates; no server document analysis activated.

Rollback: revert only this enhancement through protected branch review; previous Phase 1 public chat remains intact.
