## 1. Invitation template

## 5. Review mandate record

Each assignment should record:

- reviewer;
- version/date reviewed;
- scope and excluded questions;
- evidence supplied;
- findings and severity;
- conflicts/recusals;
- unresolved issues;
- WPA response/remediation decision;
- whether a follow-up review is required.

## 6. Standing boundaries

1. AAB review is not state accreditation, legal recognition or institutional endorsement.
2. A reviewer comment cannot silently become WPA doctrine.
3. Methodology v1.0 is not finalised merely because an invitation was sent.
4. Public names require written acceptance + COI declaration + Public Listing Consent.
5. Human governance retains final institutional and authorial responsibility.
