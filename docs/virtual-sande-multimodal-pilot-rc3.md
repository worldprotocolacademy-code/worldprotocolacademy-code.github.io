Browser voice intentionally disabled in protected pilot pending privacy review, public voice unchanged.

Evidence: SHA-256 identifies submitted bytes, HMAC receipt binds extraction to Access subject and expiry (2h), and for vision to submitted question. This establishes integrity of the receipt, not accuracy of observations, custody, or independent authentication of the original image. Excerpts are untrusted data. Vision descriptions and text transcriptions are tentative, not certified OCR. PDF conversion is not validated page-level extraction. Synthesis separates observation, evidence, interpretation, assessment and limitations. Optional public corpus lookup uses only a separately typed public topic, with separate consent; no automatic query from private file content, no ingestion into corpus. Search retrieval is not independent source verification.
