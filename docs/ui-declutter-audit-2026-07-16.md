# WPA UI Declutter Audit — 2026-07-16

## Core finding

The platform has strong institutional content, but the current interface presents too many parallel links, icons, badges and calls to action with similar visual weight. This dilutes hierarchy and makes WPA appear as a collection of portals rather than a disciplined institutional system.

## Binding principles

1. One dominant action per page.
2. Maximum three secondary actions above the fold.
3. Use icons only where they carry stable semantic meaning; no decorative emoji in institutional navigation.
4. Virtual Sande should be contextually available, not globally duplicated.
5. Home is an entry/decision page; Institute is an authoritative institutional page.
6. Public tools, services, research and learning must be grouped into four clear verticals.
7. Duplicate links between Home and Institute must be removed or demoted.

## Immediate correction

- Restrict the universal Virtual Sande floating widget to selected gateway and service pages.
- Keep existing dedicated AI interfaces untouched.
- Remove decorative emoji from runtime-injected Institute navigation labels.
- Preserve the existing Home, Papers and Institute implementations without duplication.

## Next controlled pass

- Reduce Home top navigation to: Home, Programmes, Certification, Institute, Publications, Services, Tools, Languages.
- Reduce Institute top navigation to: Identity, Charter, Research, Methodology, Publications, Trust, Contact.
- Move detailed links into grouped secondary navigation or footer.
- Consolidate repeated CTA clusters into one primary and two secondary actions per section.
