# WPA Institute Daily Product v1.2

Status: LIVE DYNAMIC DAILY PRODUCT · SCHEDULED VERIFIED ARCHIVE · HUMAN GATE
Date: 2026-10-29

## Purpose

WPA Institute Daily Product closes the operational gap between live public-source monitoring and a usable daily Institute output.

The product is not an automatic scientific publication. It is a finished daily briefing package prepared automatically for Human Gate review.

## Canonical A → B chain

1. WPA Journal Live authoritative public-source packet
2. API freshness gate
3. publication-date and source-URL provenance gate
4. source-health gate
5. relevance and source-confidence thresholds
6. five-domain classification:
   - Protocol
   - Diplomacy
   - Public Relations
   - Security
   - Communicology
7. deterministic ranking, deduplication and diversity limits (maximum 3 items per source family and per domain after domain seeding)
8. executive snapshot + WPA working angle + recommended production route for every selected item
9. daily package generation:
   - HTML
   - Markdown
   - provenance JSON
10. dated archive and latest pointer
11. Human Gate

## Canonical outputs

Public live product:
- /institute/daily/
- browser-downloadable provenance JSON
- browser-downloadable Markdown

Scheduled institutional archive:
- GitHub Actions artifact containing latest + dated HTML/Markdown/JSON generated by the server-side deterministic generator
- 90-day artifact retention in the current workflow

Repository source-of-truth references:
- /data/institute-daily/index.json
- /docs/WPA_INSTITUTE_DAILY_PRODUCT_v1.md

## Automation

Workflow: .github/workflows/wpa-institute-daily-product.yml

Default cadence: daily at 04:17 UTC, plus manual dispatch.

The workflow also runs once after the generator/workflow is activated on main.

The public page generates the current brief directly from Journal Live with fail-closed freshness and quality gates, so no daily repository write or PR is required.

The scheduled workflow independently regenerates the same class of HTML/Markdown/JSON package, runs the Product Health Gate and uploads the verified package as a 90-day GitHub Actions artifact. This preserves a dated institutional archive without weakening protected-main rules or creating daily merge races.

## Input hierarchy

Primary current input: WPA Journal Live.

WPA Watch and Journal Watch may provide complementary editorial context only when their freshness gate passes. A stale Watch feed must never override a fresh Journal Live packet.

Academic Search Hub is a discovery/verification planning layer, not the default daily live feed.

Pilot 20 is an institutional evidence/validation backend. It is consulted only for relevant institutional-comparison or benchmark contexts and never auto-applies a guarded canonical patch.

Sublimate remains a deterministic source/output architecture and optional isolated Worker runtime. The daily product has a repository-hosted execution path so output does not depend on Cloudflare Worker activation.

## Acceptance criteria

A daily run passes only when:

- the Journal Live packet has a valid generated_at timestamp;
- the packet is within the configured API-age limit;
- selected items have valid original-source URLs and published_at timestamps;
- source-health failures are excluded;
- every selected item passes minimum relevance and source-confidence thresholds;
- at least 3 items are selected;
- at least 2 WPA domains are represented;
- at least 2 source families are represented;
- every selected item contains a WPA working angle and recommended production route;
- an executive snapshot with a lead item is generated;
- HTML, Markdown and JSON are all generated;
- the scheduled archive artifact is created without modifying protected main;
- Human Gate remains PENDING;
- automatic external publication remains false.

## Human Gate boundary

Automation may prepare and archive the daily product.

Human approval remains required before:

- journal article, Working Paper or Protocol Note publication;
- doctrine or canonical institutional claims;
- DOI assignment;
- external platform posting;
- reuse of third-party visuals;
- presenting a candidate as an independently verified WPA finding.

## Failure behaviour

If the API is stale, unavailable, malformed, too sparse, or fails domain/source thresholds, both the public live surface and the scheduled archive fail closed. The live surface shows that a current daily product is unavailable rather than presenting stale material as current.

A missing daily edition is preferable to unsupported output.

## Governance formula

Fresh public source → provenance → deterministic selection → Daily Product → Human Gate → consequential release.

Automation builds. Human Authority remains final.

## Release architecture v1.2

The daily website output is no longer coupled to a protected-main write. This is intentional: the public product is computed from the fresh canonical Journal Live packet in the browser, while the scheduled job creates an independently health-gated archive artifact. Branch protection remains unchanged.
