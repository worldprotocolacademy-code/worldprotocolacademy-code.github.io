# WPA Protocol Living Lab — Open Badges 3.0 Readiness Gate

**Status:** DESIGN / NOT ISSUING. This dossier is a readiness checklist and does not enable credential issuance, payments, professional licensing, user profiles or a public credential registry.

## Standards reference

- Open Badges 3.0 specification: https://standards.1edtech.org/open-badges/specifications/standards/v3p0
- Open Badges implementation guide: https://standards.1edtech.org/open-badges/guides/standards/v3p0/impl

Open Badges 3.0 is an ecosystem for structured digitally verifiable claims about achievement; creating a badge-shaped JSON object is **not** sufficient to assert 1EdTech certification or institutional recognition.

## Mandatory gates before any future issuance

1. **Legal issuer and capacity:** establish the accurate legal person/role responsible for issuance, consumer rights and contractual obligations. WPA is presently an independent digital platform, not a separately registered legal institution.
2. **Award rules:** externally and internally reviewed learning outcomes, time/assessment design, pass threshold, reasonable accommodation, retakes, appeals, fraud and AI-use policy.
3. **Identity and consent:** consent and identity verification suitable to the actual lawful purpose; minimise personal data, define retention and exercise deletion/access rights.
4. **Issuance security:** credential cryptographic signing, issuer key governance, verification, expiration, correction and revocation with a tested recovery plan.
5. **Audit and fairness:** provenance, assessor conflicts, documented user evaluation and external methodological review.
6. **Machine verifiability:** implement against the applicable Open Badges 3.0 technical specification, then test interoperability and conformance rather than self-declare certification.
7. **Human Gate:** explicit manual institutional approval of programme and each release-level policy, followed by exact deployment evidence.

## Strict current boundary

The three Living Lab simulations offer *pedagogical feedback only*. Scores **must not** be used to issue or imply certificates, badges, licences or accreditation. No badge issuer, credential wallet, learner registry, payment component or identity verification is part of v0.1.

**Human action required:** formal legal/educational decision and independent review before the separate credential implementation project is started.
