About this package

This page provides access to the consolidated WPA Global Institutions Master List v1.0-CORRECTED-4F-REV2. The package includes the URL-restored master dataset, public-readable Markdown file, CSV/JSON files, URL restoration log, QA report and changelog.

The dataset is intended for internal review, research structuring, institutional mapping and further source verification. It is not presented as a final public ranking, accreditation list, official recognition list or verified institutional benchmark.

Status: Pre-publication candidate / internal review. Not final public benchmark until wider source verification and institutional review are completed.
Key correction: v1.0-CORRECTED-4F-REV2 restores website URL fields where safely resolvable. A005 and B008 remain reported cooperation-model observations with no URL and no source-verified institutional-entity status.
D001/A010 live clarification: D001 — Protocol Academy of Macedonia is shown as VERIFIED — primary source and retained as the canonical institutional entity. A010 — Protocol Academy of Kosovo is retained as an audit-visible child / branch / brand-presence record under D001 and is not counted as a separate independent institution pending the next full entity-resolution pass. Public counts remain unchanged.

Use and limitations

This package is a working institutional audit and should be used with caution. It is suitable for internal review, research planning, taxonomy development, comparative mapping and future verification workflows.

It should not be cited as a final public benchmark, official accreditation list, governmental recognition list or fully verified institutional ranking.

Verification notice: The wider external dataset remains subject to source verification. URL restoration does not mean that an institution or record has been fully source-verified.
