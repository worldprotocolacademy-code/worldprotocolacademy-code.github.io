# WPA Institute Global Aggregator · v1.5

Status: **LIMITED_PRODUCTION / HUMAN_GOVERNED**

Canonical route: `/media/`

## Scope lock
Only:
- Protocol
- Diplomacy
- Public Relations
- Security
- Communicology

General politics, sport, entertainment, lifestyle and unrelated business/technology do not enter the Daily Brief unless there is a clear, source-checkable connection to one of the five domains.

## Architecture
Public/authorised source signal → scope classifier → source/evidence role → candidate queue → attributed paraphrase → WPA observation → WPA analysis → exact presenter script → Sande Human Gate → READY-TO-POST / authorised adapter → measurement → correction/learning.

## Presenters
**Протоколка** and **Дипломат** use versioned identity locks. Production avatars should be photorealistic fictional humans in navy suits with white shirts and dark bow/neck-bow styling, with radiophonic voices and natural diction. Browser speech is a pilot convenience, not production-grade phoneme lip-sync.

## Source catalog
`/media/data/source-catalog.json` contains institutional, news, specialist, PR, protocol, hospitality, radio/podcast, AI and discovery source families. Most external entries are intentionally **CANDIDATE_VERIFICATION_REQUIRED** until the original publisher/root/feed is checked. Inclusion is not endorsement and not verification of each story.

## Global diplomatic layer
The 197-record WPA Symbols dataset is used only as a geography backbone. MFA/embassy/mission roots must be independently verified before activation. International bodies are seeded as candidates and must pass the same verification discipline.

## Human Gate
No public publication, email outreach, platform posting, doctrine change, credential action or commercial activation is represented as automatic. An APPROVED Human Gate decision prepares release, but external delivery is claimed only when a real authorised adapter returns a delivery result.

## Growth
The growth flywheel optimises repeatable organic growth using source quality, timeliness, viewer value, retention, shares, saves and follow conversion. It does not promise a follower count or income.

## PWA
`/media/manifest.json` and `/media/sw.js` provide an installable web-app shell. Native Android/iOS packaging can reuse the same backend/governance layer later; Play Store/App Store publication requires separate developer accounts, privacy disclosures, platform review and store compliance.
