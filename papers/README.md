# WPA Papers Archive

This directory contains PDF files that WPA has a confirmed basis to redistribute. It is not the canonical numbering source for the academic corpus.

## Canonical citation style

WPA uses **APA 7th edition (author-date)** for academic reference display. BibTeX and RIS remain additional interchange formats.
