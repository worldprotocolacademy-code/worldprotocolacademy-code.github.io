Анти-имперсонациско правило

Име, лого, фотографија, email display name или цитат од WPA не се доказ за идентитет. За барање што вклучува пристап, пари, лозинка, API клуч, документ за идентификација, договор, сертификат или институционална обврска, проверката мора да се направи независно преку канонската WPA страница или контактот погоре.

WPA никогаш не бара преку ненадејна порака

  • Google/Gmail, GitHub или Cloudflare лозинка;
  • 2FA код, passkey или recovery code;
  • API secret, GitHub token или Cloudflare token;
  • PIN или целосни банкарски credentials;
  • итно префрлање средства на непроверена сметка за „заштита“ на профил.

Ако добиеш сомнителна порака

  1. Не кликај на линкот и не отворај прилог.
  2. Отвори ја услугата директно преку позната адреса/bookmark.
  3. Провери recent security activity и devices.
  4. Ако активноста не е твоја, прекини ја сесијата и обезбеди ја сметката.
  5. Зачувај subject, sender, time и headers без да објавуваш secrets.
  6. Пријави WPA impersonation на sande@worldprotocolacademy.mk.
