## Core rule

Legacy content is **idea inventory, not publication-ready copy**.

Every imported concept starts with:

- `source_status = unverified` unless a canonical / official source has already been attached;
- `risk = elevated` when intent, motive, humiliation, revenge, political signalling or other contested interpretation is asserted;
- `rights = pending` until footage / images / music are cleared;
- `publication_status = blocked` until Source Gate + Rights Gate + Brand/Governance + Sande Gate pass.

## Script conversion rule

1. Preserve the strongest factual hook if verified.
2. Separate **event fact** from **WPA interpretation**.
3. Never state motive as fact without evidence.
4. Replace absolutes with jurisdiction / context where needed.
5. Use one primary CTA.
6. Prefer 15–30 sec for Discovery unless the case genuinely needs more context.
7. Use Sande on camera as the default trust layer; AI avatar is a localisation / scaling option.
8. Use owned, licensed, public-domain or independently created visuals only.
9. Capture real retention / completion / comments / shares / saves / profile visits.
10. If a format wins, create 5–10 adjacent controlled tests before abandoning it.
